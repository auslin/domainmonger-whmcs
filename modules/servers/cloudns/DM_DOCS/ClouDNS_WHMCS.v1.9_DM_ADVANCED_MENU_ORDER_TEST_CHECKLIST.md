# ClouDNS WHMCS v1.9 DM Advanced Menu Order Test Checklist

## Advanced Dropdown
- Open a DNS zone in the WHMCS client area.
- Hover/click Advanced on the main menu.
- Confirm this order:
  1. SOA
  2. DNSSEC
  3. separator
  4. SSL
  5. Zone Transfers
  6. separator
  7. Import Zone File
  8. Export Zone File
  9. separator
  10. Deactivate Zone

## Mobile Menu
- Resize to mobile width or test on a phone.
- Open Settings Menu.
- Confirm the Advanced section uses the same order and labels.

## Link Check
- Click each Advanced item and confirm it opens the expected page.
